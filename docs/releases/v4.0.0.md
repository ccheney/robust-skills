# v4.0.0 — Focused skill triggering and workflows

This major release revises all 11 skills using OpenAI's
[recent skill-authoring guidance](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra).
Skills now select for the actual task, load conditional guidance from references,
and preserve the user's chosen architecture, tools, and scope.

## Breaking changes

- **Narrower automatic selection.** Generic frontend, backend, database,
  visualization, and messaging requests no longer imply every related skill.
  FSD work, domain architecture, Mermaid output, card layout, and text formatting
  have distinct selection boundaries.
- **Workflow guidance is task-scoped.** Blanket architecture adoption, fixed
  aggregate-size thresholds, global CSS resets, and unnecessary broad reading
  or testing instructions have been removed or qualified.
- **Entrypoints and documentation anchors changed.** `SKILL.md` files now route
  to detailed references. Slack text guidance is split into `RENDERERS.md`,
  `SYNTAX.md`, and `MESSAGE-BEHAVIOR.md`; Slack streaming has `STREAMING.md`.
  Duplicate Mermaid and Postgres skill-local README files were removed.

## Migration

Update installed skills from this release. Names and `--skill` installation
selectors are unchanged. If a workflow relied on a broad keyword trigger,
describe the specific task or explicitly invoke `$skill-name` in Codex.
Explicit invocation still respects the user's requested scope and tool choices.

Move links to removed entrypoint sections or skill-local READMEs to the relevant
reference or the repository README. All 77 prior technical references and the
Teams payload linter remain available; no new connector is required. Existing
UI metadata and default automatic-invocation policy are preserved.

## Validation

- All 11 skills pass the OpenAI skill-creator structural validator.
- Repository metadata, resource links, and evaluation coverage pass; nine
  invalid temporary fixtures verify the validator's error paths.
- Independent manual selection matches 55/55 expected cases; 11 concrete
  workflow outputs were reviewed.
- JavaScript behavior checks pass on Node 24.11.1; generated messaging JSON
  parses and the Teams Graph linter reports no errors or warnings.

This was not a live host activation benchmark or a fresh verification of every
platform-support claim. Target Node 20, Mermaid/browser rendering, Bazel builds,
database execution, and live Slack/Teams delivery were unavailable or outside
the bounded examples. The [audit](https://github.com/ccheney/robust-skills/blob/v4.0.0/docs/skill-authoring-audit.md) records the scope,
per-skill changes, measurements, and reusable evaluation cases.

Description text shrank from 7,368 to 2,312 characters (69%); combined entrypoints
shrank from 2,851 to 510 lines (82%).
